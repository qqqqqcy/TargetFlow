# 主要交互动效

统一时序位于 `Utilities/DayflowMotion.swift`：选中态采用 0.28 秒低回弹弹簧，页面内容采用 0.20 秒淡入淡出并移动 6 点，弹窗呈现采用 0.32 秒低回弹弹簧。开启系统“减少动态效果”时，新增页面过渡只保留 0.12 秒淡化，共享悬停与按压反馈关闭缩放。

覆盖的交互：

- 左侧时间线／设置：选中背景通过 matched geometry 平滑移动，右侧页面淡入。
- 设置内部 tab：整个内容容器参与过渡，包括隐私页独立的滚动结构，避免容器直接跳变。
- 日／周：保留既有切换编排，将缩放幅度从 5% 收敛到 2%；减少动态效果时只淡化。
- 日视图摘要／活动详情：选择与取消选择均由局部状态动画驱动。
- 事件与目标弹窗：呈现／关闭淡化，详情／颜色步骤切换淡化并轻微移动。
- 通用按钮：按下即缩放反馈，松开立即执行动作，移除原来人为增加的 80／100 毫秒动作延迟。

动画仅挂在对应状态变化的局部容器，避免将时间线实时刷新和表单编辑整体动画化。保留周视图详情栏已有的布局与内容分段编排。
